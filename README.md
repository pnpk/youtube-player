# 練習プレーヤー

YouTube の動画を見ながら楽器を練習するための Web アプリです。区間をくりかえし再生(A-B ループ)したり、速度を落としたりする操作を、楽器を持ったまま数タップでできます。

**URL: https://pnpk.github.io/youtube-player/**

## 開き方

iPad やスマホでは、**Safari のブックマーク(またはタブ)から開いてください。**

ホーム画面に追加したアイコンから起動すると、YouTube Premium のログイン状態が引き継がれず、広告が出ます。Safari から開けば、Premium に加入していれば広告は出ません。

## 基本の使い方

1. 上の欄に YouTube の URL を貼って「読み込む」を押す
   - 共有ボタンからコピーした URL(`youtu.be/…`、`?si=…` 付きなど)をそのまま貼れます
   - 欄の右端の「×」で、中身を一度に消せます
2. ▶ で再生し、練習したいフレーズの頭で **A**、終わりで **B** を押す
   - B を押すとすぐループが始まり、B を過ぎるたびに A へ戻ります
3. 必要なら速度を下げる(**−5% / +5%**)
4. 位置がずれていたら、A / B の横の **−0.1 / +0.1** で 0.1 秒ずつ直す

ループをやめるときは、再生バーの右の **×** を押します。

## ボタン

| ボタン | 動き |
|---|---|
| ⟲ 3秒 | 今の位置から 3 秒戻る |
| ▶ / ❚❚ | 再生 / 一時停止 |
| 頭に戻る | 今ループしている範囲の頭から再生する(区間を選んでいればその区間の頭、なければ A、A もなければ動画の先頭) |
| A / B | 押した瞬間の位置を A / B にする。B は A より 0.1 秒以上後ろで押す |
| −0.1 / +0.1 | A / B を 0.1 秒ずつ動かす |
| −5% / +5% | 速度を 5% ずつ変える(50〜100%) |
| 速度の表示(例: 85%) | タップすると 100% に戻る |
| 再生バー | タップした位置へ移動。指を置いたままスライドすると時刻の表示がついてきて、離した位置へ移動する |

## 区切り(A-B の中をさらに分けて練習する)

長いフレーズを小さく分けて、一部分だけをくりかえせます。

1. 再生しながら、区切りたい位置で **＋区切り** を押す
2. 区切ると **全体 / 1 / 2 / 3 …** のボタンが出るので、練習したい区間の番号を押す
   - その区間だけをループします。**全体** で A-B 全体のループに戻ります
3. 間違えた区切りは、その近くで **−区切り** を押すと消えます

- A / B を決める前でも ＋区切り を押せます。そのときは A が動画の先頭、B が動画の最後になります。あとで A / B を押せば、その位置に移ります(A-B の外になった区切りは消えます)
- 区切りは 9 個(区間は 10 個)まで入れられます
- 区間が多いときは、番号のボタンの列を横にスクロールして選びます

## 履歴

「履歴」ボタンで、これまでに開いた動画の一覧が出ます(新しい順に 30 件まで)。

- タップするとその動画を開き、前回の **A / B・速度・区切り** も戻ります
- 「×」でその 1 件を消せます
- 練習中に変えた設定は自動で保存されます。ページを開き直すと、最後に開いた動画がその設定のまま戻ります(自動では再生しません)

履歴はその端末のブラウザの中だけに保存されます。ほかの端末とは共有されず、ブラウザのデータを消すと履歴も消えます。

## 画面の向き

画面の大きさと向きに合わせて並べ方が変わります。

- **スマホ(縦)**: 動画が上、ボタンが下
- **iPad(縦)**: 動画が上、ボタンが下(A と B の操作を 1 段に並べる)
- **iPad(横)・PC・スマホ(横)**: 動画が左、ボタンが右

## うまくいかないとき

- **「この動画は埋め込み再生が許可されていません」と出る**: 投稿者が埋め込み再生を禁止している動画です。YouTube アプリで見てください
- **「プレーヤーを読み込めませんでした」と出る**: ネット接続を確認して、ページを開き直してください
- **B から A に戻るときに一瞬止まる**: YouTube のプレーヤーが戻った位置を読み込み直すためで、なくすことはできません。フレーズの頭が途切れて気になるときは、A を −0.1 で少し手前にずらしてください

## 開発メモ

ビルドの仕組みやフレームワークは使わない、HTML / CSS / JavaScript(ES Modules)だけの静的サイトです。YouTube IFrame Player API で動画を埋め込んでいます。

| ファイル | 役割 |
|---|---|
| `index.html` / `style.css` | 画面と 3 種類のレイアウト |
| `app.js` | ボタン・ループの監視(50ms ごと)・画面の更新 |
| `loop.js` | A/B・速度・URL 解析の計算 |
| `sections.js` | 区切りと区間の計算 |
| `history.js` | 履歴の追加・並べ替え・削除・壊れたデータの扱い |
| `storage.js` | 履歴の保存と読み込み(`localStorage`) |
| `player.js` | YouTube プレーヤーの薄いラッパー |
| `tools/stamp-version.mjs` | JS / CSS の版番号を `index.html` に書き込む |

### テスト

```sh
npm test
```

Node.js の標準テストランナーを使います。追加のパッケージは不要です。

### 更新と公開

1. JS / CSS を変えたら、版番号を書き込む

   ```sh
   npm run stamp
   ```

   GitHub Pages はファイルを 10 分間ブラウザに保存させるので、版番号を変えないと、更新直後に新しい HTML と古い JS が混ざることがあります。書き込み忘れは `npm test` が失敗して知らせます。

2. `npm test` が通ることを確かめて、`main` に push する。GitHub Pages に自動で公開されます

設計の詳細は `docs/superpowers/specs/`、実機での確認項目は `docs/manual-check.md` にあります。
