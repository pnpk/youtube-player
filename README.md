# 練習プレーヤー

YouTube の動画を見ながら楽器を練習するための Web アプリです。区間をくりかえし再生(A-B ループ)したり、速度を落としたりする操作を、楽器を持ったまま数タップでできます。

**URL: https://pnpk.github.io/youtube-player/**

## 開き方

iPad やスマホでは、**Safari のブックマーク(またはタブ)から開いてください。**

ホーム画面に追加したアイコンから起動すると、YouTube Premium のログイン状態が引き継がれず、広告が出ます。Safari から開けば、Premium に加入していれば広告は出ません。

## 基本の使い方

1. 上の欄に YouTube の URL を貼り付ける。貼り付けるとすぐ読み込みます(手で入力したときは「開く」を押す)
   - 共有ボタンからコピーした URL(`youtu.be/…`、`?si=…` 付きなど)をそのまま貼れます
   - 欄の右端の「×」で、中身を一度に消せます
2. ▶ で再生し、練習したいフレーズの頭で青い **A**、終わりで青い **B** を押す
   - B を押すとすぐループが始まり、B を過ぎるたびに A へ戻ります
3. 必要なら「速度」の **− / +** で速度を下げる(5% ずつ)
4. 位置がずれていたら、A / B の横の **− / +** で 0.1 秒ずつ直す。再生バーの下に出る**ループバー**で、A / B のつまみをドラッグしても動かせます

ループをやめるときは、「ループ」の見出しの右の **解除** を押します。

## ボタン

| ボタン | 動き |
|---|---|
| ↺3(丸い矢印) | 今の位置から 3 秒戻る |
| ▶ / ❚❚ | 再生 / 一時停止 |
| ⏮(縦線つきの左向き三角) | 今ループしている範囲の頭から再生する(区間を選んでいればその区間の頭、なければ A、A もなければ動画の先頭) |
| A / B | 押した瞬間の位置を A / B にする。B は A より 0.1 秒以上後ろで押す |
| A / B の横の − / + | A / B を 0.1 秒ずつ動かす |
| 速度の − / + | 速度を 5% ずつ変える(50〜100%) |
| 速度の数字(例: 85%) | タップすると 100% に戻る |
| ♪(URL 欄の右) | 音声ファイル(MP3 / WAV)を開く |
| 再生バー | タップした位置へ移動。指を置いたままスライドすると時刻の表示がついてきて、離した位置へ移動する |
| ループバー(A / B を設定すると再生バーの下に出る) | A-B の付近だけを拡大して表示。A / B のつまみを 0.1 秒単位でドラッグできる。ドラッグ中は、つまみの上に時刻と元の位置からの差(例: +0.3秒)が出て、元の位置に薄い影が残る。秒の目盛り・区切り・再生位置も見える。バーをタップ、または指を置いたままスライドすると、その位置へ移動(スライド中は再生位置の線と時刻が指についてくる。移動先は A から B の 0.1 秒手前までに収まる) |
| ループの行の A の時刻 | タップすると A へ移動する |

## ヘルプ

URL 欄の右端の **?(丸の中に?)のアイコン** で、アプリの中で使い方のヘルプを開けます(キーボードでは ? キー)。基本の使い方・ボタン・区切り・履歴・キーボード操作・うまくいかないときの対処をまとめています。

## キーボード操作(PC)

| キー | 動き |
|---|---|
| スペース | 再生 / 一時停止 |
| ← / → | 3 秒戻る / 3 秒進む |
| Shift + ← / → | 10 秒戻る / 10 秒進む |
| ↑ / ↓ | 速度 +5% / −5% |
| A / B | 今の位置を A / B にする |
| Shift + A | A へ移動 |
| R | 頭に戻る |
| M | ＋ 区切り |
| 1〜9 / 0 | 区間 1〜9 を選ぶ / 全体に戻す |
| ? | ヘルプを開く / 閉じる |
| Esc | ヘルプ・履歴を閉じる |

- URL 欄に入力しているあいだは、キー操作は効きません
- ボタンにマウスを乗せると、対応するキーが表示されます
- 動画の画面そのものをクリックすると、キー入力が YouTube のプレーヤー側に取られ、YouTube 標準の操作(←/→ で 5 秒移動など)になります。動画の外側をクリックすると、この表のキーに戻ります

## 区切り(A-B の中をさらに分けて練習する)

長いフレーズを小さく分けて、一部分だけをくりかえせます。

1. 再生しながら、区切りたい位置で **＋区切り** を押す
2. 区切ると **全体 / 1 / 2 / 3 …** のボタンが出るので、練習したい区間の番号を押す
   - 区間には番号ごとに色が付きます(1 青・2 緑・3 オレンジ・4 紫・5 ピンク・6 水色・7 藍・8 黄・9 赤・10 ミント)。ループバーの帯とボタンの丸が同じ色になり、選んでいる区間はループバーで濃く表示されます
   - その区間だけをループします。**全体** で A-B 全体のループに戻ります
3. 間違えた区切りは、その近くで **−区切り** を押すと消えます
4. 区切りの位置を直したいときは、ループバーの白い縦長のつまみをドラッグします(0.1 秒単位。隣の区切りや A / B は追い越しません。ドラッグ中は時刻と元の位置からの差が出ます)

- A / B を決める前でも ＋区切り を押せます。そのときは A が動画の先頭、B が動画の最後になります。あとで A / B を押せば、その位置に移ります(A-B の外になった区切りは消えます)
- 区切りは 9 個(区間は 10 個)まで入れられます
- 区間が多いときは、番号のボタンの列を横にスクロールして選びます

## 音声ファイル(MP3 / WAV)

手持ちの音声ファイルでも、YouTube と同じように練習できます。

- URL 欄の右の **♪** でファイルを選びます(iPad では「ファイル」アプリから。PC ではページにドラッグ & ドロップしても開けます)
- 動画の枠のところに**曲全体の波形**が出ます。A-B の範囲は青、選んだ区間はその区間の色になり、波形をタップ・スライドするとその位置へ移動します。ループバーの背景にも拡大した波形が出ます
- 開いたファイルはこのブラウザの中に保存され(合計 1GB まで。超えたら最後に開いたのが古いものから消えます)、履歴(♪ 付き)から選ぶだけで開けます。消えていたら、同じファイルを ♪ から選び直すと前回の設定が戻ります
- 履歴から「削除」すると、保存したファイルと波形も消えます
- 速度を落としても音程は変わりません
- MP3・WAV のほか、ブラウザが対応している形式(M4A など)も開けます

## 履歴

URL 欄の右端の **時計のアイコン** で、これまでに開いた動画の一覧が出ます(新しい順に 30 件まで)。右上の「完了」か、一覧の外側をタップすると閉じます。

- タップするとその動画を開き、前回の **A / B・速度・区切り** も戻ります
- 「削除」でその 1 件を消せます
- 行の左のアイコンで種類が分かります(赤地に ▶ が YouTube、青地に ♪ が音声ファイル)。音声ファイルは大きさも表示し、ブラウザに保存されていないものには「未保存」と出ます(選び直しが必要)。一覧の上には、保存中の音声ファイルの合計(上限 1 GB)が出ます
- 練習中に変えた設定は自動で保存されます。ページを開き直すと、最後に開いた動画がその設定のまま戻ります(自動では再生しません)

履歴と音声ファイルは、その端末のブラウザの中だけに保存されます。ほかの端末とは共有されず、ブラウザのデータを消すと消えます。Safari では、しばらく(7 日ほど)このページを開かないと保存データが消えることがあります。

## 画面

iOS の設定アプリのような見た目で、端末のライト / ダークモードに合わせて色が切り替わります。画面の大きさと向きに合わせて並べ方も変わります。

- **スマホ(縦)**: 動画が上、ボタンが下
- **iPad(縦)**: 動画が上、ボタンが下(A と B を横に並べ、その下に速度と区切りを左右に並べる)
- **iPad(横)・PC・スマホ(横)**: 動画が左、ボタンが右

## うまくいかないとき

- **「この動画は埋め込み再生が許可されていません」と出る**: 投稿者が埋め込み再生を禁止している動画です。YouTube アプリで見てください
- **「プレーヤーを読み込めませんでした」と出る**: ネット接続を確認して、ページを開き直してください
- **B から A に戻るときに一瞬止まる**: YouTube のプレーヤーが戻った位置を読み込み直すためで、なくすことはできません。フレーズの頭が途切れて気になるときは、A の − で少し手前にずらしてください

## 開発メモ

ビルドの仕組みやフレームワークは使わない、HTML / CSS / JavaScript(ES Modules)だけの静的サイトです。YouTube IFrame Player API で動画を埋め込んでいます。

| ファイル | 役割 |
|---|---|
| `index.html` / `style.css` | 画面と 3 種類のレイアウト |
| `app.js` | ボタン・ループの監視(50ms ごと)・画面の更新 |
| `loop.js` | A/B・速度・URL 解析の計算 |
| `sections.js` | 区切りと区間の計算 |
| `keys.js` | キーボード操作の割り当て |
| `history.js` | 履歴の追加・並べ替え・削除・壊れたデータの扱い |
| `storage.js` | 履歴の保存と読み込み(`localStorage`) |
| `player.js` | YouTube プレーヤーの薄いラッパー |
| `audio-player.js` | 音声ファイルのプレーヤー(`player.js` と同じ操作の形) |
| `waveform.js` | 波形の計算と描画 |
| `media-store.js` | 音声ファイルと波形の保存(IndexedDB) |
| `tools/stamp-version.mjs` | JS / CSS の版番号を `index.html` に書き込む |

### テスト

```sh
npm test
```

Node.js の標準テストランナーを使います。追加のパッケージは不要です。

### 更新と公開

1. JS / CSS を変えたら、版番号を書き込む

   ```sh
   npm run stamp
   ```

   GitHub Pages はファイルを 10 分間ブラウザに保存させるので、版番号を変えないと、更新直後に新しい HTML と古い JS が混ざることがあります。書き込み忘れは `npm test` が失敗して知らせます。

2. `npm test` が通ることを確かめて、`main` に push する。GitHub Pages に自動で公開されます

設計の詳細は `docs/superpowers/specs/`、実機での確認項目は `docs/manual-check.md` にあります。
