## 区切り・再生バー(2026-10-04 追加)
- [ ] A-B ループ中に「＋区切り」で区切りが入り、「全体」「1」「2」… が出る
- [ ] 区間を選ぶとその区間だけをループし、「全体」で元に戻る。「頭に戻る」は選んだ区間の頭へ戻る
- [ ] A が未設定のときに「頭に戻る」を押すと、動画の先頭から再生する
- [ ] 「−区切り」で今の位置に近い区切りが消える
- [ ] A だけ押して「＋区切り」を押すと、B が動画の最後に設定されて区切りが入る。そのあと B を押すと B がその位置に移り、区切りは残る
- [ ] A も押さずに「＋区切り」を押すと、A が動画の先頭・B が動画の最後に設定されて区切りが入る
- [ ] A/B を動かして区切りが外に出ると、その区切りが消える
- [ ] 履歴から選び直すと区切りも戻る
- [ ] 再生バーを指でスライドすると時刻の表示が動き、離した位置へ移動する。スライド中に画面がスクロールしない
