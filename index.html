    ヘルプ

    基本の使い方

    1. 上の欄に YouTube の URL を貼り付けます。貼り付けるとすぐ読み込みます(手で入力したときは「開く」)。
    2. で再生し、練習したいフレーズの頭で A、終わりで B を押します。B を押すとループが始まり、B を過ぎるたびに A へ戻ります。
    3. 「速度」の − / + で速度を下げます(5% ずつ、50〜100%)。数字をタップすると 100% に戻ります。
    4. 位置がずれていたら、A / B の横の − / + で 0.1 秒ずつ直します。再生バーの下に出るループバーで、A / B の丸いつまみをドラッグしても動かせます。

    ループをやめるときは、「ループ」の見出しの右の「解除」を押します。

    ボタン

    • 3 秒戻る
    • 再生 / 一時停止
    • 頭に戻る(選んだ区間の頭 → A → 動画の先頭の順)
    • 履歴
    • このヘルプ
    • URL 欄の中身を消す

    再生バーはタップでその位置へ移動します。指を置いたままスライドすると時刻がついてきて、離した位置へ移動します。ループの行の A の時刻をタップすると A へ移動します。

    ループバーは A-B の付近だけを拡大した表示です。A / B のつまみを 0.1 秒単位でドラッグでき、区切り(青い線)や再生位置(黒い線)、秒の目盛りも見えます。ドラッグ中は、つまみの上に時刻と元の位置からの差(例: +0.3秒)が出て、元の位置には薄い影が残ります。バーをタップするか、指を置いたままスライドすると、その位置へ移動します(A から B の少し手前までの範囲で止まります)。

    区切り

    • 再生しながら「＋ 区切り」を押すと、その位置で A-B を区間に分けます。
    • 「全体 / 1 / 2 …」で区間を選ぶと、その区間だけをループします。「全体」で元に戻ります。
    • 区間には番号ごとに色が付きます(1 青・2 緑・3 オレンジ…)。ループバーの帯とボタンの丸が同じ色なので、どの番号がどこかが一目で分かります。選んでいる区間はループバーで濃く表示されます。
    • 「− 区切り」は、今の位置にいちばん近い区切りを消します。
    • A / B を決める前でも押せます。そのときは A が動画の先頭、B が動画の最後になり、あとで A / B を押すとその位置に移ります。

    履歴

    • 開いた動画は新しい順に 30 件まで残ります。選ぶと、前回の A / B・速度・区切りも戻ります。
    • 設定は自動で保存されます。ページを開き直すと、最後の動画がその設定のまま戻ります。
    • 履歴はこの端末のブラウザの中だけに保存されます。

    うまくいかないとき

    • 広告が出る: ホーム画面のアイコンからではなく、Safari のブックマークから開いてください。
    • 「埋め込み再生が許可されていません」: 投稿者が埋め込みを禁止している動画です。YouTube アプリで見てください。
    • B から A に戻るときに一瞬止まる: YouTube の読み込み直しのためで、なくせません。頭が途切れるときは A を少し手前にずらしてください。
